Корпоративная почта обнаружена именно в метаданных первоначального коммита и устранена до публикации. Для последующих коммитов применяется выбранная пользователем локальная Git-идентичность.
- Gitleaks 8.30.1 получен из официального GitHub Release, SHA256 сверён с опубликованными checksum. `gitleaks git --log-opts=main --redact` и `gitleaks dir` на чистом `git archive` не обнаружили секретов. Код и данные не передавались внешнему сервису сканирования. Отчёты остались вне репозитория.
- Локальный `.git/hooks/pre-push` проверяет всю историю каждого отправляемого ref (включая прошлые версии удалённых файлов), декодированные Git-объекты, метаданные и пути; запрещает локальные/сборочные данные. При ошибке самой проверки также запрещает push. Сам hook и его реализация не входят в коммиты.
- Проверка hook: 9 синтетических сценариев (чистый, латиница, кириллица, смешанный регистр, имя файла, автор, сообщение, удалённое из последней версии содержимое, UTF-16, артефакты — некоторые признаки объединены в сценарии); 2 настоящих push в временные локальные bare-репозитории: чистый разрешён, запрещённое слово в истории блокирует передачу. Секретные значения в вывод не печатаются.
- `git ls-files -ci --exclude-standard` пуст: игнорируемые файлы не отслеживаются. Проверены реальные старые APK, окружения, SDK, local.properties и контрольные пути секретов/данных/логов через `git check-ignore`. В экспорт не попадают APK, ключи, данные, сборки, зависимости и `.git`.
- Проведён ручной просмотр тестовых событий, литералов учётных данных и сетевых адресов: тестовые записи искусственные, серверы Exchange — example.org; адреса внешних сервисов относятся к провайдерам и стандартным XML namespaces.

Граница проверки: публикуемая Git-история и экспорт, а не уничтожение локальных старых APK, кэшей и записей reflog. Они не отправляются при push ветки. Проверка по маркерам/секретам не является полным аудитом безопасности приложения. Физический телефон и Windows не проверялись. Итог первого push фиксируется после ответа remote.

Результат: первый push `main` выполнен после всех проверок. GitHub принял `81f6ae3dabd212631a720551dbc5a7c61c9144bf`; `git ls-remote --symref origin HEAD refs/heads/main` подтвердил этот SHA и основную ветку `main`. Отправлялись только refs/heads/main, без тегов, APK и релизов. Следующий документирующий коммит проходит тот же локальный pre-push.
