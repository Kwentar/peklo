## RUN-002 — 2026-11-07 — Предпубликационный аудит
Mac / macOS 15, arm64. База исходников: первоначальный коммит с исправленным автором; далее изменялись только документы. Функциональные тесты и сборка из RUN-001 относятся к тем же исходникам приложения, повторный прогон без изменения кода не заявляется.

- GitHub API и `git ls-remote`: `Kwentar/peklo` публичный, перед первым push refs отсутствовали. Remote настроен по SSH. Видимость не изменялась.
- Проверены все файлы текущего дерева, скрытые файлы и объекты всей отправляемой истории: содержимое, имена путей, автор/коммитер и сообщения. Корпоративная почта обнаружена именно в метаданных первоначального коммита и устранена до публикации. Для последующих коммитов применяется выбранная пользователем локальная Git-идентичность.
- Gitleaks 8.30.1 получен из официального GitHub Release, SHA256 сверён с опубликованными checksum. `gitleaks git --log-opts=main --redact` и `gitleaks dir` на чистом `git archive` не обнаружили секретов. Код и данные не передавались внешнему сервису сканирования. Отчёты остались вне репозитория.
- Локальный `.git/hooks/pre-push` проверяет всю историю каждого отправляемого ref (включая прошлые версии удалённых файлов), декодированные Git-объекты, метаданные и пути; запрещает локальные/сборочные данные. При ошибке самой проверки также запрещает push. Сам hook и его реализация не входят в коммиты.
- Проверка hook: 9 синтетических сценариев (чистый, латиница, кириллица, смешанный регистр, имя файла, автор, сообщение, удалённое из последней версии содержимое, UTF-16, артефакты — некоторые признаки объединены в сценарии); 2 настоящих push в временные локальные bare-репозитории: чистый разрешён, запрещённое слово в истории блокирует передачу. Секретные значения в вывод не печатаются.
- `git ls-files -ci --exclude-standard` пуст: игнорируемые файлы не отслеживаются. Проверены реальные старые APK, окружения, SDK, local.properties и контрольные пути секретов/данных/логов через `git check-ignore`. В экспорт не попадают APK, ключи, данные, сборки, зависимости и `.git`.
- Проведён ручной просмотр тестовых событий, литералов учётных данных и сетевых адресов: тестовые записи искусственные, серверы Exchange — example.org; адреса внешних сервисов относятся к провайдерам и стандартным XML namespaces.

Граница проверки: публикуемая Git-история и экспорт, а не уничтожение локальных старых APK, кэшей и записей reflog. Они не отправляются при push ветки. Проверка по маркерам/секретам не является полным аудитом безопасности приложения. Физический телефон и Windows не проверялись. Итог первого push фиксируется после ответа remote.

Результат: первый push `main` выполнен после всех проверок. GitHub принял `81f6ae3dabd212631a720551dbc5a7c61c9144bf`; `git ls-remote --symref origin HEAD refs/heads/main` подтвердил этот SHA и основную ветку `main`. Отправлялись только refs/heads/main, без тегов, APK и релизов. Следующий документирующий коммит проходит тот же локальный pre-push. Изменения карточки мета-проекта сохранены локально, в его GitLab remote не отправлялись.

## RUN-003 — 2026-11-08 — Android UI и виджет 0.4.0
Mac / macOS 15, arm64; JDK 17, Gradle 8.9, SDK 35. База `ac50a76`, локальные изменения исходников и документов; проверки выполнялись до коммита. Версия 0.4.0 / versionCode 4.

- `./build.sh :app:assembleDebugAndroidTest`: debug APK и тестовый APK собраны, все 13 JVM-тестов прошли. Новые тесты проверяют границы дня, порог 30 минут, пересечения и сохранение всех 40 событий при группировке. Веб не менялся, его тесты повторно не запускались.
- Создан отдельный AVD с Android 15 AOSP ATD arm64, включена отрисовка. `adb -s emulator-5554 install -r ...` обновил ранее установленную 0.3.0 без удаления приложения. Это не проверка обновления физического телефона или реальных аккаунтов.
- После установки app и androidTest APK: `adb -s emulator-5554 shell appwidget grantbind --package ru.ryadom.calendar`; `adb -s emulator-5554 shell setprop debug.hwui.drawing_enabled 1`; `adb -s emulator-5554 shell am instrument -w ru.ryadom.calendar.test/androidx.test.runner.AndroidJUnitRunner` — 2 теста прошли. Инструментальные тесты защищены проверкой emulator hardware и используют только синтетические данные.
- UiTest привязывает настоящий AppWidgetHost: проверяет стрелки, возврат к автоматической дате, календарь и выбор конкретного дня, переход в событие, отсутствие вертикального обрезания строк и названий. Проверены размерные RemoteViews Android 12+ и резервный вариант размеров. Малый вариант 280×260 dp показывает группу вместо обрезания.
- Просмотрены скриншоты расписания, подробностей, календарей, настроек, полного и компактного виджетов, следующего дня и выбора даты. Профили: 1080×2400 / 420 dpi; 1440×3120 / 560 dpi (размер Pixel 6 Pro); 960×1920 / 480 dpi со шрифтом 130%. Найдено и исправлено обрезание нижней навигации. В тестовом хосте устранена гонка восстановления Activity после закрытия диалога; финальный прогон успешен.
- `apksigner verify --print-certs`: APK валидна, SHA-256 сертификата совпадает с прежней локальной 0.2.0. Приватные ключи не копировались.
- `adb ... shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.LAUNCHER ru.ryadom.calendar`: найден MainActivity. Добавлены адаптивная, круглая и тематическая иконки с фоном.

Физический Pixel 6 Pro, Windows, реальные аккаунты, Doze и фоновые уведомления новой версии на устройстве не проверены. Проверка уведомления в DeviceTest относится к тестовому эмулятору. Команды сборки/запуска и зависимости не менялись; карточка мета-проекта в этом этапе не редактировалась.
